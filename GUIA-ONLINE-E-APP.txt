AMOR PET — COLOCAR ONLINE E INSTALAR COMO APP

IMPORTANTE SOBRE CUSTOS
O arquivo render.yaml prepara uma hospedagem Render com disco persistente (plano Starter), que pode ter custo mensal. Confira o preço atual antes de confirmar. Evite hospedagem gratuita sem disco persistente: contas, mensagens e progresso guardados em arquivo podem ser perdidos quando o serviço reinicia ou é publicado novamente.

PARTE A — ENVIAR O PROJETO PARA O GITHUB
1. Entre em https://github.com/ e crie uma conta ou entre.
2. Clique no + e depois em New repository.
3. Dê o nome amor-pet, marque Private se quiser manter o código privado e clique em Create repository.
4. Na página do repositório, clique em “uploading an existing file”.
5. Abra a pasta amor-pet que veio dentro do ZIP no seu PC. Selecione os arquivos e pastas DENTRO dela (não envie a pasta externa vazia) e arraste para a página do GitHub.
6. Aguarde o envio e clique em Commit changes. Confira se server.js, package.json, render.yaml e a pasta public estão na raiz do repositório.

PARTE B — PUBLICAR O SERVIDOR NO RENDER
1. Entre em https://render.com/ e crie uma conta.
2. No painel, escolha New + e Blueprint.
3. Conecte sua conta GitHub e selecione o repositório amor-pet.
4. O Render vai ler render.yaml. Revise os recursos e o custo antes de criar o serviço. O disco persistente pode exigir plano pago.
5. Clique para aplicar/criar e aguarde a implantação terminar.
6. Abra o serviço Web e copie a URL pública terminada em onrender.com. Abra-a no navegador; deve aparecer o Amor Pet. O endereço /api/health deve mostrar uma resposta JSON com ok:true.
7. Guarde a URL: é o endereço do jogo para ambos. Não é necessário manter o PC ligado depois que o serviço online estiver publicado.

PARTE C — CONECTAR O CASAL
1. Abra a URL pública no PC ou celular.
2. Uma pessoa cria conta e gera o convite privado.
3. A outra pessoa abre a MESMA URL, cria uma conta diferente e aceita o código.
4. Ambos devem usar essa URL sempre, não localhost.

PARTE D — INSTALAR COMO APP NO ANDROID
1. Abra a URL HTTPS do Amor Pet no Chrome.
2. Toque no menu de três pontinhos.
3. Escolha “Instalar app” ou “Adicionar à tela inicial” (o nome varia).
4. Confirme. O ícone Amor Pet aparece na tela inicial.

PARTE E — INSTALAR NO IPHONE
1. Abra a URL HTTPS no Safari.
2. Toque no botão Compartilhar.
3. Escolha “Adicionar à Tela de Início”.
4. Confirme.

PARTE F — INSTALAR NO PC
1. Abra a URL HTTPS no Chrome ou Edge.
2. Procure o ícone de instalar na barra de endereço ou abra o menu do navegador.
3. Escolha “Instalar Amor Pet” ou “Instalar este site como aplicativo”, se aparecer.

NOTIFICAÇÕES
O jogo pode mostrar notificações enquanto está aberto e o navegador permite. Notificações confiáveis quando o site está fechado, principalmente em iPhone, podem exigir configuração adicional e não são garantidas por este projeto. Para permitir avisos, abra o jogo e use “Ativar avisos”.

SEGURANÇA E CÓPIA DE SEGURANÇA
Use senha exclusiva e não compartilhe seu código de convite publicamente. Este projeto é uma versão inicial; antes de usar com dados sensíveis ou publicar para muita gente, é recomendável reforçar proteção contra tentativas de login e configurar backups do arquivo /var/data/data.json.


VERSAO GRATUITA NO RENDER
- O render.yaml desta versao usa plan: free e nao cria disco pago.
- O servidor usa um arquivo JSON local como banco de dados. No Render gratuito, esse arquivo pode ser apagado quando o servico reiniciar, dormir ou for publicado novamente. Use apenas para testes; nao guarde informacoes importantes.
- O servico gratuito pode demorar cerca de um minuto para acordar depois de ficar parado.
- Para manter contas, mensagens e progresso do pet de forma confiavel, sera necessario adaptar o projeto para um banco de dados externo persistente.
